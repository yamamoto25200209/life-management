# 火災保険 比較・確認事項

- 最終更新日：2026年11月19日
- 用途：不動産会社との契約打ち合わせにおける火災保険の確認
- ステータス：比較・確認中

## 1. 検討の目的

新居の賃貸契約にあたり、加入する火災保険を選定する。

不動産会社から求められる補償条件を満たしたうえで、補償内容と保険料のバランスがよい保険を選びたい。

特に以下を重視する。

- 借家人賠償責任と個人賠償責任の両方を確保する
- それぞれの補償限度額が不動産会社の条件を満たす
- 婚姻関係のない同居パートナーも補償対象にできる
- 不必要な補償を避け、保険料を抑える
- 建物の構造による保険料の違いを確認する

## 2. 比較対象の保険

### 2-1. シャーメゾンライフGUARD

| 項目          | 内容                    |
| ----------- | --------------------- |
| 保険料         | 2年間 15,000円           |
| 年換算         | 7,500円                |
| 借家人賠償責任     | 1,000万円               |
| 個人賠償責任      | 1,000万円               |
| 同居パートナー     | 補償対象と認識している（最終確認は未実施） |
| 建物構造による保険料差 | 確認が必要                 |

**補償内容について**

借家人賠償責任と個人賠償責任は、それぞれ1,000万円と聞いている。

**同居パートナーについて**

婚姻関係のない同居パートナーについても補償対象になると認識している。

ただし、以下については正式な確認が必要。

- 家財補償に同居パートナーの家財も含まれるか
- 借家人賠償責任の補償対象に同居パートナーも含まれるか
- 個人賠償責任についても同居パートナーが補償対象になるか
- 同居の事実や賃貸借契約書への記載など、必要な条件は何か

**追加確認事項**

- 不動産会社が指定する加入条件を満たしているか
- 建物の構造によって保険料や補償条件が変わるか
- 同居パートナーの補償範囲と適用条件

### 2-2. ソニー少額短期保険

| 項目      | 内容        |
| ------- | --------- |
| 保険料     | 年間 5,000円 |
| 家財補償    | 300万円     |
| 修理費用補償  | 100万円     |
| 借家人賠償責任 | 1,000万円   |
| 個人賠償責任  | 1,000万円   |
| 自己負担額   | 0円        |

**特徴**

- 年間保険料が5,000円で、比較候補の中では安価。
- 借家人賠償責任と個人賠償責任がそれぞれ1,000万円。
- 家財補償300万円、修理費用補償100万円。
- 自己負担額0円の条件で比較している。

**同居パートナーについて**

保険会社から、1契約で同居パートナーも補償対象にできる旨の公式回答を得ている。

ただし、補償対象となる範囲や適用条件については、契約内容・約款に照らして最終確認する。

特に確認すること：

- 家財補償に同居パートナーの家財も含まれるか
- 借家人賠償責任の補償対象に同居パートナーも含まれるか
- 個人賠償責任についても同居パートナーが補償対象になるか
- 同居の事実や賃貸借契約書への記載など、必要な条件は何か

**建物構造について**

不動産会社から建物の正式な構造・耐火区分などの回答を得た後、構造によって保険料が変わるかを保険会社に確認する。

### 2-3. 損保ジャパン「THE 家財の保険」

| 項目        | 内容            |
| --------- | ------------- |
| 基本保険料の見積額 | 年間 約6,200円    |
| 個人賠償責任特約  | 年間 約2,050円    |
| 合計        | 年間 約8,250円    |
| 借家人賠償責任   | 1,000万円の条件で検討 |
| 個人賠償責任    | 無制限の条件で検討     |

**特徴**

- 個人賠償責任は無制限の補償を検討できる。
- 個人賠償責任特約の保険料は年間約2,050円。
- 借家人賠償責任・個人賠償責任は特約で追加する構成。
- 個人賠償責任については、婚姻関係のない同居人も補償対象に含まれる可能性があることを公式FAQで確認済み。

**注意事項**

- 借家人賠償責任の限度額と保険料は見積内容の最終確認が必要。
- 同居パートナーが補償対象になる条件を確認する。
- 賃貸借契約書に同居人として記載されている必要があるか確認する。
- 保険契約上、同居人としてどのように取り扱われるか確認する。

## 6. 現時点の比較・判断

現時点では、ソニー少額短期保険が年間5,000円であり、補償内容と保険料のバランスから有力候補となっている。

ただし、次の事項が確定するまでは加入先を決定しない。

1. 不動産会社が求める補償条件
2. 借家人賠償責任・個人賠償責任の各1,000万円という条件の扱い
3. 婚姻関係のない同居パートナーの補償範囲
4. 建物構造による保険料の違い
5. 保険の補償開始日

シャーメゾンライフGUARDについても、借家人賠償責任・個人賠償責任がそれぞれ1,000万円であることを前提に比較する。同居パートナーについても補償対象と認識しているが、補償範囲と適用条件を最終確認する。

損保ジャパンは、個人賠償責任を無制限にできる点が特徴だが、年間保険料は約8,250円となるため、必要な補償とのバランスで判断する。

## 9. 情報の確度・注意事項

この資料は過去の相談内容を整理した比較メモであり、保険会社の正式な見積書や約款の代わりではない。

- シャーメゾンライフGUARDの借家人賠償責任・個人賠償責任は、それぞれ1,000万円と聞いている。
- シャーメゾンライフGUARDの同居パートナーへの補償は、現時点では対象と認識しているが、適用条件は未確認。
- 保険料は相談時点の見積・案内に基づく。
- 補償限度額・同居人の取り扱いは、契約条件と約款で最終確認する。
- 不動産会社の加入条件は、契約打ち合わせで確認する。
- 未確認事項は確定情報として扱わない。
- 個人情報や契約識別情報は記載しない。
